# 🚀 CareersAnalysis — AI ATS Resume Auditor & Career Roadmap Generator

An end-to-end web application that audits resumes against ATS screening parameters, identifies missing technical competencies, calculates expected pay scales, and builds targeted weekly career roadmaps using Google Gemini models.

🔗 **Live Application:** [ai-resume-analyzer-2jxj.onrender.com](https://ai-resume-analyzer-2jxj.onrender.com/)

---

## ✨ Key Features

* **Instant ATS Score:** Evaluates profiles against industry screening benchmarks.
* **Skill Gap Analysis:** Pinpoints matched technical competencies and missing high-yield skills.
* **Pay-Scale Benchmarking:** Projects salary ranges and career progression for Corporate, PSU, and Government roles.
* **Personalized Roadmaps & Viva:** Generates phased weekly learning plans and role-specific interview/CBT questions.
* **Dual-Language Output:** Professional English and clear Hindi (Devanagari) explanations.
* **Resilient Architecture:** Implements multi-key rotation and model fallbacks to maintain uptime across API rate limits.

---

## 🛠️ Tech Stack

* **Backend:** Python 3.11, Flask, Jinja2
* **Database & Auth:** TiDB Cloud (Serverless MySQL), SQLAlchemy
* **AI Engine:** Google Gemini API (`gemini-3.6-flash`, `gemini-2.5-flash`, `gemini-1.5-flash`)
* **Frontend:** Tailwind CSS, HTML5, Vanilla JavaScript
* **Hosting & DevOps:** Render, Gunicorn
* **SEO & Crawling:** Google Search Console verified, XML Sitemaps, structured `robots.txt`
